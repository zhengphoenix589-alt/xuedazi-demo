# 学搭子 · 微观经济学学习 Demo

> 从看懂视频，到真正会做题。

学搭子是一款面向长视频学习场景的 AI 伴学产品 Demo。它把 B 站课程整理成章节、考点、知识结构、课程笔记、AI 问答、闯关练习和复习任务，帮助学生知道自己学到哪里、掌握了什么，以及下一步应该复习什么。

## 在线体验

[打开学搭子 · 微观经济学学习 Demo](https://zhengphoenix589-alt.github.io/xuedazi-demo/)

当前 Demo 使用《范里安微观经济学现代观点》作为课程样例，重点展示：

- 第 28/51 集：完全信息静态博弈（一）；
- 课程首页与学习进度；
- 课程识别与整理过程；
- 课程知识地图；
- 视频章节与重点内容；
- AI 学习助手；
- 收益矩阵闯关检测；
- 学习结果与复习卡片。

## 它想解决什么问题

长视频学习的困难不只是“视频太长”，还包括：

- 看完容易忘，无法说清自己学到了什么；
- 不知道怎样把一小时以上的视频拆成学习单元；
- 很难整理出完整、可复习的课程笔记；
- 缺少围绕当前内容的提问和互动；
- 做题后只看到对错，不知道薄弱点在哪里；
- 中断之后难以继续，也不知道下一步该做什么。

学搭子希望把视频从一段连续播放的内容，变成一个可以导航、理解、提问、练习和复习的学习空间。

## 当前页面包含什么

### 1. 学习首页

首页提供学习总览：

- 本周学习进度；
- 已完成的知识点；
- 上次正在学习的课程；
- 继续学习入口；
- 今日复习任务。

页面首先回答两个问题：

> 我上次学到哪里了？下一步应该做什么？

### 2. 导入视频与课程整理

页面保留了导入视频入口。用户可以粘贴 B 站视频链接，查看课程识别和整理过程：

```text
识别视频标题和课程信息
→ 提取字幕并切分学习章节
→ 建立知识点之间的关系
→ 生成练习题和复习卡片
```

为了保证公开展示稳定，当前页面已经载入一节微观经济学课程示例，不需要输入账号、Cookie 或 API Key。

### 3. 课程导览

进入课程后，页面先展示本节课的整体学习地图，包括：

- 本节课程主题；
- 学完后应该能够回答的问题；
- 基础概念；
- 分析工具；
- 核心结论；
- 建议学习顺序。

当前示例“完全信息静态博弈（一）”的知识结构为：

```text
基础概念
参与者 · 策略 · 收益

分析工具
收益矩阵 · 最优回应 · 占优策略

核心结论
纳什均衡：没有人愿意单独改变策略
```

### 4. 视频学习工作台

学习工作台把视频和课程材料放在一起，学生可以按章节学习，并回到相应时间点复习。

当前课程章节包括：

| 章节 | 时间 |
| --- | --- |
| 导入：为什么要研究博弈？ | 00:00 |
| 完全信息静态博弈 | 18:32 |
| 参与者与策略 | 31:08 |
| 收益矩阵 | 42:18 |
| 最优回应与纳什均衡 | 57:46 |
| 例题解析 | 1:09:20 |

工作台中可以查看：

- 重点讲解；
- 课程笔记；
- 思维导图；
- 我的笔记；
- AI 学习助手；
- 当前章节进度。

### 5. AI 学习助手

AI 学习助手围绕当前课程内容提供学习支持，可以尝试：

- “什么是完全信息静态博弈？”
- “用生活中的例子解释纳什均衡。”
- “帮我出一道收益矩阵题。”

它的定位不是替学生看完视频，而是帮助学生解释概念、换一种方式理解，并进入下一步练习。

### 6. 闯关式检测

学生可以通过三道题检查自己是否理解收益矩阵和纳什均衡。

示例题：

> 在下面这个收益矩阵中，如果参与者 B 选择“左”，参与者 A 的最优回应是什么？

| A \\ B | 左 | 右 |
| --- | --- | --- |
| 上 | 3, 2 | 1, 1 |
| 下 | 2, 1 | 4, 3 |

答题后会获得即时反馈，并生成一张后续复习时可以使用的复习卡片。

### 7. 学习结果与复习卡片

完成一轮学习后，页面会展示：

- 已掌握知识点；
- 待复习知识点；
- 本次练习正确率；
- 建议回看的时间点；
- 关联练习和课程笔记。

学习结果会继续转化为下一次的复习任务，例如：

- 纳什均衡与最优回应的区别；
- 如何从收益矩阵找到占优策略；
- 完全信息静态博弈的三个要素。

## 当前 Demo 的实现边界

这是一个用于课程项目展示的前端 Demo，重点是验证产品流程、界面结构和学习交互，不是完整的线上视频平台。

当前页面：

- 可以直接通过 GitHub Pages 打开；
- 不需要安装依赖；
- 不需要配置 API Key；
- 使用内置微观经济学课程示例；
- 通过页面交互展示课程整理、问答、检测和复习流程。

以下能力目前不作为公开 Demo 的通用能力承诺：

- 任意 B 站视频的稳定字幕提取；
- 任意学科内容的高质量自动整理；
- 真实用户账号与云端学习记录；
- 对学生开放回答的完整正确性评估；
- 正式考试或高风险场景下的自动评分。

## 本地打开

本目录中的 `index.html` 是早期固定视频学习 Demo 页面，可以直接用浏览器打开：

```bash
open index.html
```

也可以启动本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000
```

## 项目定位

学搭子不是单纯的播放器，也不是替学生完成学习的聊天机器人。它想做的是一个长视频学习工作台：

```text
从视频中找到结构
→ 用自己的方式理解
→ 通过提问和练习暴露薄弱点
→ 把错误转化为复习任务
→ 中断后能够继续学习
```

最终希望帮助学生形成一套即使暂时没有 AI，也能继续使用的长视频自学方法。
